# Touchline Dynasty — сборка для интеграционного тестирования

Статус: НЕ подтверждённый релиз. Имя RELEASE задано техническим заданием и не означает прохождение Studio/live-приёмки. Исходный проект переработан, но часть требований ещё не завершена; см. DEVELOPMENT_GAPS_RU.md. Старый QA не относится к новой версии и сохранён в baseline.

1. Откройте TouchlineDynasty_RELEASE.rbxlx в Roblox Studio. Сначала сохраните копию. Для существующего проекта есть INSTALL_STUDIO.lua: Command Bar в Edit mode. Установщик отказывается работать при занятых именах Touchline; чужие объекты не удаляет. Предпочтителен готовый place.
2. Запустите Play. Проверьте профиль, состав, покупки NPC, ручной матч, симуляцию и переход сезона. Любая ошибка Output блокирует публикацию.
3. Studio использует отдельный DataStore TouchlineDynasty_TEST_v2, live — существующий TouchlineDynasty_v1. При недоступном API Studio допускает временный профиль с явным статусом. Это НЕ сохранение. Production при ошибке загрузки не создаёт замену профилю.
4. Для реальных проверок опубликуйте отдельную закрытую тестовую experience и включите Studio Access to API Services только там. Не подключайте тестовую experience к production-хранилищам через внешний код. Пройдите RELEASE_CHECKLIST_RU.md до публичного доступа.
5. В src/MonetizationConfig.lua все Roblox ID равны 0: реальные покупки отключены. Создайте продукты и passes именно этой experience, перенесите ID и пересоберите place. Внутриигровые названия и цены Roblox запрашиваются клиентом; платёж выдаётся только серверным ProcessReceipt после записи профиля. Бюджет клуба за Robux не продаётся.
6. Источник перевода английский; локальные словари en/ru/uk. Импорт и cloud-настройки — LOCALIZATION_RU.md. Автоперевод Dashboard здесь не включался.

## Воспроизводимая сборка и проверки

Python 3: `python build.py`. В Linux с системной liblua5.4: `python tests/native_check.py`. Дополнительные Python/Lupa-тесты требуют установленную lupa; в этой среде библиотека не установлена, поэтому новый runner использует настоящую системную Lua 5.4 через ctypes. Это не эмуляция Roblox.

`python localization/build_locales.py` пересоздаёт словари из strings.tsv. `python tests/balance_native.py` выполняет 1000 карьер по 30 сезонов и записывает CSV. Не запускайте агрегированные тесты в сервере Roblox.

## Миграция

Сохраняются деньги, состав с прежними ID, инфраструктура, трофеи и старые результаты. Сезон v1 завершается на старом календаре 8 клубов/14 туров, затем игра переходит в новую систему. Миграция schema 1→2 применяется один раз; некорректные или неизвестные схемы не обнуляются. Старые дисбалансные деньги не конфискуются. Сохраните независимую резервную копию production-данных перед первым обновлением.

## Производительность

12 одновременных матчей не подтверждены. Для закрытого пилота задайте MaxPlayers=1 в настройках place. Это ограничение риска, а не измеренная гарантия безопасности. Поднимать лимит можно после Studio/live-замеров. Ни телефонные FPS, ни 30-минутная утечка в Roblox не проверены.

## Новые действия

- «Помощь» → свободная тренировка и интерактивное обучение; «Задания» → два испытания. Эти матчи изолированы от календаря и футбольных денег. Первый успех каждого испытания выдаёт 25 косметических жетонов.
- «Состав» → автоматический подбор доступных 11 по ролям. Он учитывает позицию и выносливость; изучите результат перед продажами.
- Матч → «Тактика»: стили, замены и продолжение. Две паузы по 30 секунд на матч; после их использования для замены дождитесь стандартной остановки.
- Ключевые моменты: нейтральная игра ускоряется до 4× неизменными шагами 0,05 с; управление включается при подходах к штрафным. В пенальти ускорения нет. Переключение режима не перезапускает матч, но исключает его из глобальной категории.
- «Задания» → глобальные рекорды: отдельные категории manual/highlights/simulate × easy/normal/hard. Studio пишет в TD_TEST_records_v2_, live в TD_records_v2_. Очки до установки Records.lua задним числом не восстанавливаются.
- При массовых дисквалификациях центр клуба предлагает состав, восстановление или подтверждённое техническое поражение без дохода/XP. Недоступных футболистов на поле принудительно не выпускает.
- Матчевый отчёт → оценки и факторы; магазин применяет расцветку, полосы, герб, газон, значок и акценты табло.

Дополнительные диагностические отчёты: STYLE_REPORT_RU.md (500 матчей полного ядра) и SOAK_REPORT_RU.md (30 игровых минут ускоренного ядра, не реальные 30 минут Roblox).

## Последние изменения

Между матчами команда восстанавливается по игровым датам бесплатно. Врач и медицинская база увеличивают скорость; платная сессия не нужна, если к следующей встрече хватает обычного восстановления. Подготовка матча и зарплаты сохраняются однократно.

Карточка игрока → «Развитие»: назначение тренировки, скаутинг, исходящая аренда. В аренде игрок недоступен своему клубу до конца сезона, клуб делит зарплату пополам, развитие идёт по игровым датам. Карточка → «Контракт» → история. Академия использует ту же карточку. Регион скаута выбирается в разделе персонала.

Центр клуба → оформление: имя проходит серверную фильтрацию Roblox; бесплатные варианты дизайна доступны без pass. Премиальные варианты требуют действующего identity-pass. До подключения собственных pass ID покупка отключена.

В assets/audio находятся четыре самостоятельно синтезированных WAV и генератор. Загрузите их в Creator Dashboard, разрешите experience, перенесите ID в AudioConfig.lua и пересоберите. До этого игра работает без звука. Дополнительные поля schema 2 мигрируют автоматически через featuresVersion; кошельки не обнуляются.
