# Аудит исходного проекта и исправлений

Исходные пять скриптов совпадали с XML place побайтно. Старые файлы сохранены в baseline. «Подтверждено» означает чтение исходного кода; Studio не использовалась.

| Проблема и статус | Место исходника | Последствия | Изменение | Проверка |
|---|---|---|---|---|
| Ограничение дизайна: 3×8, 14 туров | Career.buildLeague/schedule | Короткая карьера | WorldConfig: 8 регионов, 320 клубов, 20×16, 30 туров | native: пары, дом/выезд, 35 сезонов |
| Подтверждён арбитраж 18%→75% | Career.market/action | Бесконечные деньги | Market: бонусы/агент, окно, срок регистрации, покупатель, уникальность предложения | native: немедленная продажа/повтор покупки |
| Подтверждён сброс рынка | Career.market/finish | Меню/тур меняет предложения | Сезонные устойчивые ID, дата окна/срок/спрос | код + календарные тесты; полный UX NOT RUN |
| Подтверждены разные рейтинги | Career.strength, Match.new | Позиция влияет только на симуляцию | Общий C.effective/Players.effective | native: чужая позиция снижает силу в матче |
| Подтверждена неверная семантика выезда | Match.new/kick | Фиксированное направление | userHome, direction, смена сторон; билеты только дома | native: выездные голы/ассисты/собственные ворота |
| Подтверждён coin flip кубка | Server.finish | Нет серии пенальти | Match/Tournaments: удары, очередь, досрочное решение, sudden death | native: ручные решения/симуляция |
| Подтверждён фарм сдач | Server.finish, Career.finish | Доход/XP и старые scorer при 0:3 | Нулевые доход/XP, очистка голов/ассистов, обычные расходы | native: 31 сезон сдач и двойной finish |
| Подтверждена замена в 36 лет | Career.action season | Игрок исчезает без контекста | Старение/контракты/пенсия, предупреждение, резервная регистрация | native: 31 сезон инвариантов; UX NOT RUN |
| Ограничение дизайна: фиксированный UI | Client.resize | Мелкое управление телефона | Отдельная responsive компоновка, кнопки/виртуальные строки | Синтаксис PASS; устройства NOT RUN |
| Подтверждён полный redraw/profile | Client.draw, Server.update | Сброс scroll/нагрузка | Retained строки, scroll, публичный профиль, revision patches/resync | Код; сетевой end-to-end NOT RUN |
| Гипотеза нагрузки 20Hz/10Hz | Server.Heartbeat | Без профиля неизвестен предел | Catch-up ≤5 шагов, AI отдельно, seq/interpolation | Native timings; Roblox 12 клиентов NOT RUN |
| Ограничение: кружки и отдельный стадион | Client.match | Декорация не улучшает поле | Одна видимая 2.5D UI-сцена с фигурками/формой/тенями | Синтаксис PASS; реальный вид NOT RUN |
| Подтверждён приём только v1; гипотезы гонок | Storage.load/save | Отказ миграции, риск старой записи | schema hooks, единая очередь, lease, проверка expiry, безопасный UpdateAsync | mock adapter: повтор callbacks, потеря ответа, конкурентность, два владельца |
| Старый QA не доказывает Studio | QA_REPORT_RU | Ложное ощущение релизной готовности | Новый отчёт с PASS/FAIL/NOT RUN | Старый отчёт сохранён только в baseline |

Финализация: перед стартом сохраняется pending={op,seed}. Результат и продвижение записываются одной транзакцией; после сбоя/выхода сохранённый матч детерминированно досчитывается, а не получает новый seed. Voluntary forfeit — отдельное действие с 0:3 и без наград. Домен не принимает оппонента/суммы/счёт из remotes.

Реальные отказоустойчивость Roblox и корректность всего клиента пока не подтверждены. Тесты адаптера не заменяют два сервера и реальные DataStore. Локальный устаревший тест ожидал повышение по порядку исходных строк вместо отсортированной таблицы; исправлено именно ожидание ранга, сохранены проверки всех клубов и 35 сезонов.
