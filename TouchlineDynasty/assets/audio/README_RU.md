# Собственные звуки

kick.wav, whistle.wav, ui.wav, crowd.wav синтезированы generate.py: синусы, шум и огибающие; внешние записи и семплы не использованы. Файлы готовы к загрузке как audio assets в Creator Dashboard владельцем experience. После получения разрешений для experience задайте ID в AudioConfig.lua и пересоберите place. До этого ID=0 и fallback тихий. Музыкального трека нет; необязательное поле music можно подключить отдельно.

Клиент повторно использует Sound-объекты, учитывает настройки sfx/crowd/music, не воспроизводит повторные snapshot seq и останавливает циклы при выходе из матча. Аудио не участвует в расчёте мяча или наград. Не заявляется успешная загрузка/разрешение Roblox: доступ к аккаунту владельца отсутствует.
