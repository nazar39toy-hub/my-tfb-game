# Touchline Dynasty

Полный проект Roblox: исходники, собранный place, документация, тесты и ресурсы.

## Скачать на Windows 11

На странице этой ветки нажмите **Code → Download ZIP**, распакуйте архив и откройте **TouchlineDynasty_FINAL.rbxlx** через **File → Open from File** в Roblox Studio.

- `TouchlineDynasty/` — полная папка проекта, включая `src`, `tests`, `localization`, `assets`, `baseline` и отчёты.
- `TouchlineDynasty_FINAL.rbxlx` — готовый place.
- `TouchlineDynasty_FINAL.zip` — исходный полный архив проекта.
- `TouchlineDynasty_FULL_CODE.txt` — полный XML place как текст.
- `TouchlineDynasty_RECREATE_FULL_PROMPT_RU.md` — самодостаточный промпт восстановления с архивом внутри.
- `EXPORT_MANIFEST.json` — размеры, SHA256 и Git blob SHA1 экспортированных файлов.

Начните с `TouchlineDynasty/START_HERE_RU.md`.

## Проверки

Сохранены результаты 67 групп native/domain/mock-проверок, 1000 карьер по 30 сезонов, 500 матчей стилей и ускоренного прогона ядра. Это не проверка Roblox Studio.

Studio, реальные устройства, live DataStore и платежи не проверены. ID продуктов/pass и аудио равны 0 до настройки владельцем. Сборка не объявляется принятой для публичного релиза; детали в `TouchlineDynasty/DEVELOPMENT_GAPS_RU.md` и `RELEASE_CHECKLIST_RU.md`.
